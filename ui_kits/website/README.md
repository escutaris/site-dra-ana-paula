# UI Kit — Site institucional

Recreação hi-fi do site `anapaulateixeira.med.br`. Componentes JSX modulares + `index.html` com click-thru entre páginas principais.

## Arquivos

- `index.html` — Home completa com nav funcional e seções dos dois modos visuais
- `Nav.jsx` — navegação sticky com mobile toggle
- `Hero.jsx` — hero editorial da Home
- `ThreeColumns.jsx` — as três colunas de autoridade
- `ServiceCards.jsx` — grid de serviços (Modo Clareza)
- `BookFeature.jsx` — destaque do livro (Modo Profundidade)
- `MarqueeKeywords.jsx` — marquee horizontal de palavras-chave
- `Pullquote.jsx` — citação editorial
- `ResearchCards.jsx` — cards de referências acadêmicas
- `Footer.jsx` — rodapé verde-noturno

Herda 100% do sistema raiz (`colors_and_type.css`, `design-system.css`, `design-system.js`).
